# Dr. S. Harini — Academic & Research Portfolio

A responsive, international academic portfolio website built from Dr. S. Harini's supplied CV.

## Included
- Responsive academic homepage
- About and research profile
- Research interests and methods
- Doctoral research project
- Peer-reviewed publications and conference work
- Scopus-indexed book chapters
- Patent
- Academic experience and education
- Corporate experience
- Presentations and conference participation
- Awards and professional development
- Contact section
- Downloadable CV PDF
- Mobile navigation

## Career positioning
The website is intentionally country-neutral and states that Dr. S. Harini is **actively seeking postdoctoral research opportunities and international research collaborations**.

## Run locally
Open `index.html` in a browser.

## Publish
Upload all files in this folder to GitHub Pages, Netlify, Vercel, or another static hosting provider. Keep `Dr_Harini_CV.pdf` in the same directory as `index.html`.
